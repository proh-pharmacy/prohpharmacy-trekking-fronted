# Changelog

## [0.1.0] - Beta

### Added

- Permission-based route, sidebar, and component access controls.
- Offline customer, location, trek delivery, sale, return, and sync workflows.
- PWA session persistence and mobile driver navigation.
- Customer locations, photo uploads, GPS capture, and location management.
- Fleet vehicle and tracking-device management.
- Live Traccar vehicle tracking with WebSocket updates, metadata labels, live position refresh, and route history.
- Responsive portal and driver experiences for mobile and desktop.
- Ledger summaries, exports, and outstanding-balance filtering.

### Improved

- Trek, stop, product, delivery, return, and customer workflows.
- Data-table actions, filtering, pagination, responsive controls, and modal layouts.
- Tracking map markers, fleet filters, telemetry cards, and route controls.
- Docker build configuration for frontend environment variables.

### Validation

- Production TypeScript and Vite build passes.

# ProH Pharmacy Trekking Operations

## User Manual Outline — Version 0.1.0 Beta

This outline is the approved structure for the version 0.1.0 user manual. It follows the order in which the application should be prepared and used, so required setup is completed before dependent workflows begin.

The final manual will be written for everyday users in plain language. It will explain what each feature is for, where to find it, how to use it, common mistakes, and what to do next. It will avoid implementation details, API terminology, and internal system language.

## Part 8: Driver preparation and offline use

### 26. Prepare the driver device

- Sign in while online
- Open the assigned trek
- Wait for the trek data to load
- Install the application as a PWA
- Open the installed PWA once while online

### 27. Why the PWA is important

- Keeps the application available from the device home screen
- Allows the app to use previously downloaded data
- Reduces the risk of losing access when offline
- Prevents relying on a normal browser tab that may be closed or refreshed

### 28. What the driver can do offline

- Register customers
- Update customer details
- Add customer locations
- Record planned deliveries
- Record unplanned sales
- Record returns
- Capture supported GPS information

### 29. What requires internet

- First login
- Initial trek download
- Switching workspaces
- Uploading photos
- Loading new server data

### 30. Offline safety rules

- Do not clear browser or PWA storage
- Do not uninstall the PWA with pending work
- Check the pending notification count
- Confirm that each saved action appears in the pending list
- Reconnect before the device battery runs out where possible

## Part 13: Daily checklists

### Administrator checklist

- Regions and districts are available
- Branches are configured
- Products and prices are current
- Staff have correct access
- Vehicles and tracking devices are active

### Trek coordinator checklist

- Trek region and date are correct
- Driver, sales staff, and vehicle are assigned
- Stops are in the correct order
- Products and quantities are correct
- Trek is started only after review

### Driver checklist

- PWA is installed
- Trek was opened while online
- Stops and products are visible
- Pending actions are checked
- Offline work is synchronized before finishing
